# めざせ！ドリブルキング ドリバト！

テレビや iPad の前でボールをつきながら遊ぶ、通路ラン型のドリブルゲームです。ブラウザだけで動きます。

- 5つの世界（村・月夜の町・夕やけの橋・雪の里・マグマの城）の道を走り、奥から迫るゲートに合わせてワザを切りかえる。左右1〜2歩のステップ、ロボを抜くドライブ場面あり
- 20ワザを5ランクに整理。プレイヤーごとのランクに合わせたワザが出る（ステージクリアでは昇級しない）
- 5ワールド×6ミッション＝30ステージ、ボス、なかま、コイン、きょうのミッション、スタンプカード
- トレーニングルーム：ワザごとに ゆっくり→ふつう→ゲームの速さ の3セットとコツ
- しょうきゅうテスト：カメラありは成功率、カメラなしは おうちの人チェック
- カメラはんてい（MediaPipe Pose）は HTTPS のサイトに置いたときだけ使えます

## 置き方（GitHub Pages）
このフォルダの中身を公開リポジトリに置き、Settings → Pages → Branch: main / (root) で公開します。

## 映像と記録
カメラの映像は端末の中だけで処理し、どこにも送りません。記録はその端末のブラウザの中だけに保存されます。
