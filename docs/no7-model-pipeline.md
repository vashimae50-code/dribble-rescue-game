# No.7 新3Dモデル（no7-v2）

## いまの状態（2026-11-19）
- `models/no7-v2.glb`：新しい No.7。`tools/character-builder/` のスクリプトで自動生成したリグ付きモデル。
- 3D試験版（`/preview/?character3d=1`）では新モデルが標準。旧モデルと比べるときは `&model=legacy`。
- GLB が読めない・骨が合わないときは、コンソールに `[No.7] Replacement GLB unavailable or incompatible` と出して旧モデルに戻る。
- 本番の画面（`/`）のプレイヤーは今までどおり2Dの絵。敵（ディフェンス・ボスなど）は、試験版でも旧モデルのまま（ユニフォームの色を変えて使うため）。

## 2026-11-19 朝の更新（参考画像1・4に合わせて）
- 配色は参考画像1（青×黄、白い靴下、青×黄のくつ）。形は参考画像4（Vネック、わきの切りかえパネル、ショーツの横ライン、ボリュームのあるカーリーヘア）。
- 目・まゆ・口は、顔の前に貼った絵（`No7_FaceDecal`）で描くアニメ風に変更。顔の前はふちどりを付けない（体の頂点カラー R がふちどりの太さ）。
- 頭身は2種類：A いまのバランス（`models/no7-v2.glb`、試験版の標準）、B デフォルメ（頭 約1.6倍、`models/no7-chibi.glb`、URL に `&model=no7-chibi`）。
- ロゴ・チーム名・メーカーのマークは入れていない。

## 見た目
- 体：MakeHuman のベースメッシュ（CC0）に筋肉・身長・比率のターゲットをかけた、筋肉質なバスケ選手の体型。頭は少しだけ大きめ（1.07倍）。
- ユニフォーム：ロイヤルブルーのタンクトップ＋ひざ上のゆったりショーツ。首・そでぐり・ウエスト・すそに黄色の帯、ショーツの横に黄色のライン。
- 背番号：背中と胸に「7」（黄色、こん色のふち）。
- 髪：茶色のカーリーヘア（上にボリューム、横と後ろは短め）。
- くつ：こん色のハイカット寄りのバスケットシューズ、白いくつ底、黄色の横ラインとかかと。白い靴下。
- ゲームの中では、アニメ風の段々の影（トゥーン）と黒いふちどりで表示する（`js/character.js`）。

## 骨格と動き
- 骨の名前は旧モデルと同じ Mixamo 形式（`mixamorig:Hips` など 52本）。`js/character.js` のパワーポジション、左右ドリブル、フロントチェンジなどは、そのまま新モデルで動く。
- 基準の姿勢は、腕を約40度下げた A ポーズと、軽くまるめた指。
- 新モデルだけ、床についている足は足うらを床と平行にたもつ（つま先が床にしずまない）。旧モデルの動きは変えていない。
- モーションは GLB に焼きこまず、ゲーム側が毎フレーム骨を動かす。

## 確認のしかた
- 新モデル：`/preview/?character3d=1` → トレーニング → ワザを選ぶ。コンソールに `[No.7] Rigged replacement GLB loaded`。
- 旧モデル：`/preview/?character3d=1&model=legacy`

## 旧 GLB（original.glb）について
- 旧モデルの中身は `Armature`（0.01倍）と `Beta_Surface`・`Beta_Joints` の2つのメッシュだけで、こわれていない（ゲームでは正常に表示される）。
- Blender で読みこむと、Blender の glTF 読み込み機能が骨の表示用の形として半径1mの球（`Icosphere`、`glTF_not_exported` コレクション）を足す。人体のまわりに見える「丸い岩」はこれと考えられる。

## キャラクターを増やすとき
`tools/character-builder/README.md` を参照。設定 JSON を1つ足して実行すると、同じ骨格・同じ動きで別のキャラクターの GLB ができる。
