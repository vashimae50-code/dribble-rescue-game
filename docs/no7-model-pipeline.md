# No.7 新3Dモデル差し替え仕様（制作・検証用）

## 現状
- ゲーム本体のモーション（パワーポジション、右・左ドリブル、フロントチェンジ）は `js/character.js` が制御。
- 現在の `models/human_model.js` は既存のスキンメッシュをbase64埋め込みしたもの。髪を追加するだけでは高品質な外観にならない。
- `?character3d=1&model=no7-v2` で `models/no7-v2.glb` の読み込みを試み、欠損・互換性エラーなら従来モデルに戻る。
- **このPRは読み込み経路の実装であり、完成GLBの制作・納品ではない。**

## 3Dモデル納品要件
1. `models/no7-v2.glb` に単一のリグ付きNo.7を格納する。実際のメッシュは `SkinnedMesh` であること。
2. 既存のMixamo系の骨名を維持する。少なくとも Hips, Spine, Spine1, Spine2, Head, 左右UpLeg/Leg/Foot, Arm/ForeArm/Hand を含める。
3. スケールと前後方向を既存モデルに合わせ、足裏が床に接地する。骨格は既存アニメーションと互換性を保つ。
4. 茶色のカーリーヘア、自然な頭身と筋肉、黒いノースリーブのユニフォーム、青いトリム、背番号7、黒いバスケットシューズを3Dメッシュ・マテリアルで表現する。
5. モーションを焼き込まず、骨格をゲーム側で制御できる状態にする。テクスチャはGLB内に埋め込む。
6. モデルは正面・背面・側面で検証する。左右ドリブル・フロントチェンジで肩・股関節・膝・足首の破綻がないことを確認する。

## 検証手順
- 旧モデル: `/preview/?character3d=1&model=legacy`
- 新モデル: `/preview/?character3d=1&model=no7-v2`
- ブラウザの開発者コンソールに `[No.7] Rigged replacement GLB loaded` と出ることを確認する。
- `unavailable or incompatible` が出た場合は旧モデルへフォールバックしているため、新モデルの表示確認ができたとは扱わない。

## 次の工程
1. 上記仕様のリグ付きGLBをBlender等で制作・配置。
2. 正面・横・背面の比較とモーション検証。
3. 旧モデルに対する頂点色による塗り分けが新モデルのテクスチャを上書きしないよう、専用の材質処理へ切り替える。
4. 複数キャラクター用のモデル選択とモーション共通化。
